Import waypoints

Imports one waypoint per record from a plain .txt file, all marked with the ⛺ tent emoji. Each record is 7 lines, in this exact order, with a line containing just --- between records:

  1. Waypoint name
  2. Picture (a full image URL, or leave the line blank)
  3. Access type (e.g. Drive in site, Boat Access Only)
  4. Description
  5. Coordinates (e.g. 45.11824 °N - 76.99567 °W)
  6. What3Words location
  7. Amenities, comma-separated (e.g. Fire Pit, Privy)

Any optional line can be left blank, but all 7 lines must be present for each record.
